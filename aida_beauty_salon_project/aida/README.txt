Aida's Beauty Salon — запуск в PyCharm

1. Откройте папку aida в PyCharm.
2. Откройте Terminal.
3. Выполните: pip install -r requirements.txt
4. Запустите: python app.py
5. Откройте: http://127.0.0.1:5000
6. Админка: http://127.0.0.1:5000/admin
   Пароль по умолчанию: admin123

Перед публикацией поменяйте пароль ADMIN_PASSWORD и данные салона в app.py.
